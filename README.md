# dotam308.github.io

Personal site for Peter, Senior Software Engineer (Backend & Distributed Systems).

Live site: https://dotam308.github.io/

## Files

- `index.html` – the CV content
- `styles.css` – terminal-style theme, phone and print styles
- `avatar.jpg` – profile photo

Plain HTML and CSS only. There is no framework, build step, backend, analytics or external font.

## Publish with GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main**, folder **/ (root)** → Save.

The English teaching CV lives in a separate repository and is served at https://dotam308.github.io/teaching-cv/.

## Update

Edit `index.html`, then commit and push to `main`. When you change `styles.css`, bump the `?v=` number on its link in `index.html` so browsers load the new version.
